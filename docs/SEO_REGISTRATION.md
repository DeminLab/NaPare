## Google Search Console

### Шаг 1: Регистрация

1. Перейдите на [Google Search Console](https://search.google.com/search-console)
2. Нажмите "Начать работу"
3. Введите URL сайта: `https://napare.sano.ru`
4. Выберите способ верификации:
   - **HTML meta tag** (рекомендуется)
   - HTML file upload
   - DNS TXT record
   - Google Analytics

### Шаг 2: Верификация (HTML meta tag)

1. Google покажет meta-тег для верификации
2. Добавьте этот meta-тег в `<head>` всех страниц вашего сайта
3. Пример:
   ```html
   <meta name="google-site-verification" content="napare-verification-code" />
   ```
4. Нажмите "Проверить" в Google Search Console
5. После успешной верификации сайт будет добавлен в Search Console

### Шаг 3: Добавление карты сайта

1. В Google Search Console перейдите в "Индекс" → "Карта сайта"
2. Добавьте URL карты сайта: `https://napare.sano.ru/sitemap.xml`
3. Нажмите "Добавить карту сайта"
4. Ожидайте обработки карты сайта

### Шаг 4: Проверка robots.txt

1. Перейдите в "Индекс" → "robots.txt"
2. Проверьте содержимое robots.txt:
   ```
   User-agent: *
   Allow: /
   Disallow: /api/
   Disallow: /admin/
   Sitemap: https://napare.sano.ru/sitemap.xml
   ```

### Шаг 5: Отправка на индексацию

1. В Google Search Console перейдите в "Индекс" → "Запрос на индексацию"
2. Добавьте URL главной страницы: `https://napare.sano.ru/`
3. Нажмите "Запросить индексацию"

## Яндекс.Цель

### Шаг 1: Создание цели

1. В Яндекс.Метрика перейдите в "Цели"
2. Нажмите "Добавить цель"
3. Выберите тип цели: "URL"
4. Введите:
   - Название: `Просмотр страницы владельца`
   - Тип: `Начало посещения`
   - URL: `/owner`
5. Нажмите "Создать"

6. Повторите для других целей:
   - `Просмотр страницы о проекте`: URL `/about`
   - `Просмотр страницы возможностей`: URL `/features`
   - `Регистрация пользователя`: JavaScript-событие `register`
   - `Вход в кабинет`: JavaScript-событие `login`

### Шаг 2: Настройка JavaScript-событий

Добавьте следующий код в `apps/web-portal/src/app/layout.tsx`:

```typescript
'use client';

import { useEffect } from 'react';

export default function YandexMetrika() {
  useEffect(() => {
    // Регистрация пользователя
    window.yaCounter12345678.reachGoal('register');

    // Вход в кабинет
    window.yaCounter12345678.reachGoal('login');

    // Просмотр страницы владельца
    if (typeof window !== 'undefined' && window.location.pathname === '/owner') {
      window.yaCounter12345678.reachGoal('view_owner');
    }

    // Просмотр страницы о проекте
    if (typeof window !== 'undefined' && window.location.pathname === '/about') {
      window.yaCounter12345678.reachGoal('view_about');
    }

    // Просмотр страницы возможностей
    if (typeof window !== 'undefined' && window.location.pathname === '/features') {
      window.yaCounter12345678.reachGoal('view_features');
    }
  }, []);

  return null;
}
```

## Частые вопросы

### Q: Как изменить владельца проекта в поисковых системах?
A: Обратитесь в службу поддержки Google и Яндекс с запросом на изменение информации о владельце.

### Q: Как добавить новую страницу в карту сайта?
A: Добавьте URL в соответствующий файл `sitemap-*.xml` и перезагрузите карту сайта в поисковых системах.

### Q: Как изменить мета-теги?
A: Редактируйте файлы `apps/web-portal/src/app/*/layout.tsx` и добавьте нужные мета-теги.

### Q: Как добавить новый ключевой слово?
A: Добавьте его в мета-тег keywords на соответствующей странице.

### Q: Как проверить, правильно ли настроен robots.txt?
A: Откройте URL `https://napare.sano.ru/robots.txt` в браузере.

### Q: Как проверить, правильно ли настроена карта сайта?
A: Откройте URL `https://napare.sano.ru/sitemap.xml` в браузере.
