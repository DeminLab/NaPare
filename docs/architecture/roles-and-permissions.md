# Роли и права доступа

**Единственный источник матрицы прав.** Все модули ссылаются на этот файл.

---

## Роли

| Роль | Код | Описание | Кто |
|------|-----|----------|-----|
| Студент | `student` | Основной пользователь | Студент вуза |
| Преподаватель | `teacher` | Публикует контент в пространства пар | Преподаватель вуза |
| Куратор | `curator` | Видит и подтверждает отсутствия группы | Куратор / староста |
| Декан факультета | `faculty_dean` | Управление факультетом, аналитика | Декан |
| Зав. кафедрой | `department_head` | Управление кафедрой, расписание | Зав. кафедрой |
| Админ вуза | `university_admin` | Управление вузом, роли, расписание | Проректор / IT-отдел |
| Суперадмин | `superadmin` | Управление платформой | Команда НаПаре |
| Разработчик | `developer` | Доступ к staging, не production | Внешний разработчик |

Один пользователь может иметь **несколько ролей**.

## Разграничение данных по ролям

| Роль | Видит данные |
|------|-------------|
| **Студент** | Только свою группу, свои ДЗ, свои отсутствия |
| **Преподаватель** | Свои пары, свои студенты, свои ДЗ |
| **Куратор** | Только свою группу, все отсутствия группы |
| **Декан** | Все группы факультета, аналитика факультета |
| **Зав. кафедрой** | Все группы кафедры, преподаватели кафедры |
| **Админ вуза** | Всё в своём вузе, все роли |
| **Суперадмин** | Всё на платформе |
| **Разработчик** | Staging-данные, без production |

---

## Реализация

- Роли хранятся в `users.roles` (comma-separated string (simple-array))
- Проверка через Guards в NestJS: `@Roles('teacher')`, `@Roles('university_admin')`
- Фильтрация по `university_id` — автоматически на уровне сервисов
- Дополнительные ограничения (только свои пары, только своя группа) — в бизнес-логике модулей
