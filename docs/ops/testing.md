# Тестирование

## Покрытие

| Проект | Цель |
|--------|------|
| Backend (NestJS) | ≥ 80% |
| Web (Next.js) | ≥ 75% |
| Mobile (Flutter) | ≥ 70% |

---

## Unit-тесты

| Модуль | Что тестировать |
|--------|-----------------|
| Auth | Генерация кодов, верификация, JWT, refresh |
| Schedule | Детект изменений, парсинг, маппинг колонок |
| PairSpace | CRUD объявлений, ДЗ, файлов, сообщений |
| Absences | Расчёт затронутых пар, статусы, подтверждения |
| Notifications | Генерация, очередь, группировка, антиспам |
| Users | Валидация профиля, смена группы, экспорт данных |

---

## Integration-тесты

| # | Сценарий | Описание |
|---|----------|----------|
| 1 | Регистрация студента | Телефон → SMS → вуз → группа → профиль |
| 2 | Вход преподавателя | Email/пароль → доступ к своим парам |
| 3 | Публикация ДЗ | Создание → push → отметка «Сдано» |

| 5 | Изменение расписания | Загрузка → детект → push студентам |
| 6 | Экспорт данных | Запрос → генерация → скачивание |

## Нагрузочное тестирование

| Метрика | Цель |
|---------|------|
| Concurrent users | ≥ 1000 |
| API response time | p95 ≤ 500 мс |
| Push delivery | ≤ 3 сек |
| Schedule upload | ≤ 10 сек (10000 пар) |

Инструмент: k6.

---

## Accessibility (WCAG 2.1 AA)

- Контраст текста ≥ 4.5:1
- Тач-зоны ≥ 44×44 px
- VoiceOver / TalkBack
- Навигация клавиатурой (Web)
- Alt-тексты, ARIA-метки

---

## Мобильное тестирование

| Платформа | Мин. версия |
|-----------|-------------|
| iOS | 15.0 |
| Android | 10 |

Что тестировать: push, камера, галерея, orientation, low battery, background/foreground, слабый интернет.
