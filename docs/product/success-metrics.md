# Метрики успеха

## Ключевые метрики (MVP + пилот)

| Метрика | Цель | Источник |
|---------|------|----------|
| **WAU студентов** | ≥ 60% от состава группы | PostHog |
| **% преподавателей с контентом** | ≥ 40% | Backend |
| **NPS студентов** | ≥ 30–40 | Опрос в приложении |
| **NPS преподавателей** | ≥ 30 | Интервью |
| **Crash-free sessions** | ≥ 99% | Sentry |
| **Время узнавания об изменении** | ≤ 5 мин | Опрос |

---

## Использование

| Метрика | Описание |
|---------|----------|
| DAU / WAU / MAU | Уникальные пользователи |
| Retention D1 / D7 / D30 | Вернувшиеся через 1/7/30 дней |
| % открывают «Мой день» ≥ 3 раз/неделю | Глубина использования |
| Количество сессий на пользователя | Частота |

---

## Ценность расписания

| Метрика | Описание |
|---------|----------|
| Время от изменения до просмотра | Скорость узнавания |
| % узнавших через приложение | Эффективность канала |

---

## Контент

| Метрика | Описание |
|---------|----------|
| % преподавателей с контентом | Вовлечённость |
| Кол-во ДЗ и файлов | Объём контента |
| % пар с хотя бы одним материалом | Покрытие |

---

## Отсутствия

| Метрика | Описание |
|---------|----------|
| Доля с подтверждённой причиной | Качество данных |
| Время реакции куратора | Скорость обработки |

---

## Сбор данных

- PostHog / Amplitude — продуктовые события
- Sentry — ошибки
- Опросы в приложении (NPS + 1–2 вопроса)
- Еженедельные интервью во время пилота

---

## Критерии успешного пилота

- WAU ≥ 60%
- ≥ 40% преподавателей с контентом
- NPS ≥ 30
- Понятные причины использования (или неиспользования)
- Техническая стабильность
