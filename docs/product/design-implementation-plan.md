# Постраничная реализация дизайна

Дата начала: 12 октября 2026 года. Статус: IMPLEMENTED; локальные проверки завершены, публикация в Git выполняется.

Цель согласована владельцем в чате: реализовать постраничный план для 42 самостоятельных экранов пяти актуальных приложений. Студенческие страницы входят в согласованный объём. API, Docker/Nginx, шапки, логотипы и Avatar сохраняются.

## Контракт дизайна

- Один главный сценарий и заметное действие на каждом рабочем экране.
- Реальные данные; отсутствие сведений, пустой список и ошибка имеют разные состояния.
- Компьютер: компактные списки и таблицы, детали по запросу. Телефон: выбранный день/объект и доступные действия вместо длинной копии таблицы.
- Сохранить существующие токены и ролевые акценты. Не добавлять декоративные метрики, эффектные фоны и неподдерживаемые действия.
- Учебные сдачи и оценки остаются в Moodle. Личный прогресс означает подготовку.
- IMPLEMENTED означает внесённый код; VERIFIED — отдельно перечисленные проверки. Это не подтверждение production.

После каждой законченной группы: typecheck затронутых приложений; затем repository guards и lint. Визуальная проверка — 390, 768, 1440 px, заполненный/пустой/ошибочный экран и длинный контент. Изменение рабочего сценария требует отдельной проверки, а не только скриншота.
