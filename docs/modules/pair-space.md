# Module: Pair Space (Пространство пары)

## 1. Цель и границы

**Цель:** Ключевой дифференциатор продукта — у каждого занятия своя страница со всем контентом (объявления, ДЗ, файлы, обсуждение).

**Не делает:** Управление расписанием (schedule), статусы отсутствий (absences).

---

## 2. Сущности

| Сущность | Описание | Ключевые поля |
|----------|----------|---------------|
| PairSpace | Пространство пары | id, lesson_id, active_until |
| Announcement | Объявление преподавателя | id, pair_space_id, author_id, text, is_pinned |
| Homework | Домашнее задание | id, pair_space_id, title, description, deadline |
| HomeworkSubmission | Статус сдачи | id, homework_id, student_id, status |
| FileAttachment | Файл | id, pair_space_id, file_url, file_type, size |
| DiscussionMessage | Сообщение обсуждения | id, pair_space_id, user_id, text, parent_id |

Подробнее: [architecture/data-model.md](../architecture/data-model.md).

---

## 3. API

| Endpoint | Метод | Описание |
|----------|-------|----------|
| `/api/v1/pair-spaces/{lessonId}` | GET | Пространство пары |
| `/api/v1/pair-spaces/{lessonId}/announcements` | POST | Создать объявление |
| `/api/v1/pair-spaces/{lessonId}/homeworks` | POST | Создать ДЗ |
| `/api/v1/pair-spaces/{lessonId}/files` | POST | Загрузить файл |
| `/api/v1/homeworks/{id}/submit` | PATCH | Отметить «сдано» |
| `/api/v1/pair-spaces/{lessonId}/messages` | GET | Сообщения обсуждения |
| `/api/v1/pair-spaces/{lessonId}/messages` | POST | Написать сообщение |

Полный OpenAPI: [api/README.md](../api/README.md).

## 6. Бизнес-правила и edge-cases

1. **Время жизни:** PairSpace активен +30–60 дней после окончания пары
2. **Автосоздание:** PairSpace создаётся автоматически при создании Lesson
3. **Сдача ДЗ:** simple статус `not_submitted` / `submitted` (без оценки в MVP)
4. **Файлы:** ограничение типов (pdf, doc, ppt, изображения) и размера (≤ 50 МБ)
5. **Обсуждение:** тред, привязанный к конкретной паре (не общий чат группы)
6. **Закрепление:** преподаватель может закрепить объявление

## 8. Нефункциональные требования

| Требование | Значение |
|------------|----------|
| Latency | p95 ≤ 300 мс |
| Offline | Кэш контента пространства |
| Rate limits | 10 сообщений/мин на пользователя |

---

## 9. Критерии приёмки

- [ ] Преподаватель создаёт объявление / ДЗ / файл за минимальное число шагов
- [ ] Студент видит всё содержимое пространства конкретной пары
- [ ] Обсуждение привязано только к этой паре
- [ ] Статус сдачи ДЗ сохраняется
- [ ] Повторяющиеся ДЗ создаются корректно
- [ ] Файлы загружаются и отдаются

---

## 10. Зависимости

**Зависит от:** auth (JWT, roles), schedule (Lesson → PairSpace)
**Зависимость от:** notifications (push при публикации контента)
