# Module: My Day (Мой день)

## 1. Цель и границы

**Цель:** Главный экран студента — персональная сводка учебного дня без AI. Агрегирует данные из других модулей.

**Не делает:** Хранение данных (только читает из других модулей), управление расписанием, публикация контента.

---

## 2. Сущности

Модуль не имеет собственных сущностей. Агрегирует данные из:

| Источник | Что берётся |
|----------|-------------|
| Schedule (lessons) | Пары на сегодня |
| Schedule (lesson_changes) | Изменения с момента последнего просмотра |
| PairSpace (homeworks) | Горящие дедлайны (сегодня/завтра) |
| PairSpace (announcements, files) | Новый контент с момента последнего просмотра |
| Absences (absence_status) | Активный статус отсутствия |

---

## 6. Бизнес-правила и edge-cases

**Логика агрегации (без AI):**

```
todayLessons = lessons WHERE date == today AND group == user.group
changes = lesson_changes WHERE lesson IN todayLessons AND createdAt > lastView
hotDeadlines = homeworks WHERE deadline IN [today, tomorrow] AND status != submitted
newContent = announcements + files WHERE createdAt > lastView AND pair IN user.group
```

1. **Пустые состояния:** «Сегодня пар нет», «Нет горящих дедлайнов», «Нет нового контента»
2. **Кэширование:** при слабом интернете показывать последнее состояние
3. **Статус отсутствия:** цветной чип с возможностью изменения
4. **Навигация:** тап по карточке пары → Пространство пары, тап по ДЗ → ДЗ внутри пространства
