## Проект NaPare

**Название:** NaPare — Операционная система учебного дня студента

**Описание:** B2B2C SaaS платформа, объединяющая все аспекты учебного дня студента в одном месте: расписание, изменения, задания, материалы, обсуждения и учёт отсутствий — всё вокруг конкретной пары.

## Инструкция по регистрации в поисковых системах

### Google Search Console

1. Перейдите на https://search.google.com/search-console
2. Зарегистрируйте новый сайт: `https://napare.sano.ru`
3. Выберите способ верификации:
   - HTML meta tag
   - HTML file upload
   - DNS TXT record
4. Следуйте инструкциям для выбранного способа
5. Добавьте сайт в Google Search Console
6. Проверьте карту сайта: `https://napare.sano.ru/sitemap.xml`
7. Проверьте robots.txt: `https://napare.sano.ru/robots.txt`

### Яндекс.Вебмастер

1. Перейдите на https://webmaster.yandex.ru
2. Зарегистрируйте новый сайт: `https://napare.sano.ru`
3. Выберите способ верификации:
   - Метатег `yandex-verification`
   - HTML-файл
   - TXT-файл
   - Meta-тег `yandex-verification`
   - DNS-запись
4. Следуйте инструкциям для выбранного способа
5. Добавьте сайт в Яндекс.Вебмастер
6. Проверьте карту сайта: `https://napare.sano.ru/sitemap.xml`
7. Проверьте robots.txt: `https://napare.sano.ru/robots.txt`

### Яндекс.Метрика

1. Перейдите на https://metrika.yandex.ru
2. Создайте новую метрику для сайта
3. Получите код метрики

## Постановка на учет в Роскомнадзор

### Инструкция

1. Зарегистрируйте домен `napare.sano.ru`
2. Подготовьте информацию:
   - Название сайта
   - URL сайта
   - Имя владельца
   - Должность
   - Email
   - Страна
   - Город
3. Зарегистрируйтесь на портале e-gov: https://gosuslugi.ru
4. Зайдите в раздел "Роскомнадзор"
5. Выберите "Постановка на учет информационных ресурсов"
6. Заполните форму с информацией о сайте
7. Загрузите документы:
   - Договор с регистратором домена
   - Копию свидетельства ИП
   - Скриншот сайта
8. Отправьте заявку
9. Ожидайте рассмотрения заявки
