### Синтетические сценарии Codex CLI

Четыре успешных прогона `codex exec --model gpt-5.6-sol --sandbox read-only --ephemeral --json` в отдельном временном Git-репозитории с тестовыми файлами и копиями адаптированных инструкций. Использовался существующий вход ChatGPT, настройки модели передавались только команде. MCP, web search, hooks и плагины отключены для прогонов. Проверены коды завершения CLI, события чтения нужного `SKILL.md` и общего раздела, признаки ожидаемого результата, отсутствие MCP-вызовов и неизменность тестового дерева.

| Условия вызова | Наблюдаемый результат |
| --- | --- |
| Явно указан `$napare-qa`, проверка правки `docs/fixture.md` | Прочитаны Skill и цикл QA, в итоге указан `git diff --check -- docs/fixture.md` |
| Ревью доказательств, навык выбран по описанию без имени | Прочитаны `napare-code-review` и цикл проверки, отчёт различил чужой SHA и пропущенный E2E |
| Явно указан `$napare-devops` и путь к его инструкции, статическое сравнение двух локальных записей MCP | Прочитаны Skill и общий раздел MCP, `fixture-mcp@latest` помечен как изменяемый источник, цепочка с точной версией и lockfile как закреплённая |

Первые модельные прогоны со штатным `gpt-6.2-sol` завершались `model_not_found` для входа ChatGPT. Выбран `gpt-5.6-sol` из доступного CLI-каталога. В некоторых первых ответах с общими формулировками отсутствовали наблюдаемые чтения нужного Skill или общего раздела. При повторе добавили указание открыть инструкцию, для неявного выбора сохранили задание без имени навыка. Выбор без этого указания остаётся непроверенным в устойчивом режиме. [Официальное описание явной и неявной активации Skills](https://learn.chatgpt.com/docs/build-skills#how-chatgpt-and-codex-use-skills).

Этот этап подтверждает discovery и проверенные синтетические задачи в CLI. Desktop, продуктовые сборки и браузеры, PostgreSQL и Android, MCP runtime, hooks и production здесь не проверялись.
