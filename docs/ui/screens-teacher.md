# Экраны преподавателя

## T01. Мои пары (главный)

**Структура:**
1. Шапка: «Мои пары» + аватар
2. Переключатель: Сегодня | Ближайшие | Все
3. Список карточек пар:
   - Время + дата
   - Предмет
   - Группа
   - Аудитория
   - Индикаторы: есть новые сообщения / нет контента
4. Тап по паре → Пространство пары (режим преподавателя)

**Пустое:** «На сегодня пар нет»

---

## T02. Пространство пары (преподаватель)

Те же вкладки, что у студента, плюс:

**Быстрые действия (FAB или кнопки сверху):**
- «+ Объявление»
- «+ Задание»
- «+ Файл»

**Объявления / Задания / Файлы:**
- Можно редактировать и удалять свои
- У заданий видно, кто отметил «Сдано» (простой счётчик)

**Обсуждение:**
- Полный доступ
- Можно закреплять сообщения (опционально позже)

**Отсутствующие:**
- Отдельная вкладка или блок: список студентов, которые отметили отсутствие на эту пару

---

## T03. Быстрая публикация

Минимальный flow (≤ 40 сек):

1. Из списка пар тап «+»
2. Выбор типа: Объявление | Задание | Файл
3. Форма:
   - Объявление: текст
   - Задание: название, описание, дедлайн
   - Файл: выбор файла + название
4. Кнопка «Опубликовать»

После публикации — toast «Опубликовано» + студенты получают push.

---

## T04. Профиль преподавателя

Аналогично студенту + информация о привязанных группах/парах.
