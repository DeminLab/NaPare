# Экраны куратора (в основном Web)

## C01. Дашборд отсутствий (главный)

**Структура:**
1. Шапка: название группы + селектор группы (если несколько)
2. Фильтры:
   - Статус (Все / Ожидает / Подтверждено / Отклонено)
   - Период
   - Только неподтверждённые
3. Таблица:

| Студент | Статус | Период | Пар | Причина | Подтверждение | Действия |
|---------|--------|--------|-----|---------|---------------|----------|
| Иванов А. | 🤒 Болен | 05–07.09 | 4 | — | Ожидает | ✓ ✕ |

4. Быстрые действия в строке: Подтвердить / Отклонить
5. Массовые действия (позже)

**Клик по студенту** → детали + история статусов.

## C03. Объявление группе

Простая форма: заголовок + текст → «Отправить».  
Уходит как уведомление + появляется в ленте студентов (можно позже привязать к «Мой день»).

## C04. Список студентов группы

Имя, контакты (если разрешено), текущий статус отсутствия.
