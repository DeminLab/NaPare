# Экраны администратора вуза и суперадмина (Web)

## A01. Структура вуза

- Дерево / список: Факультеты → Курсы → Группы
- CRUD групп и факультетов
- Назначение кураторов группам

## A02. Расписание

- Загрузка файла (Excel / CSV / iCal)
- Маппинг колонок (если нужно)
- Статус последней синхронизации
- Логи ошибок
- Кнопка «Запустить синхронизацию»
- История загрузок

## A03. Пользователи и роли

- Поиск пользователей
- Назначение ролей: Teacher, Curator, UniversityAdmin
- Привязка преподавателя к парам / группам

## A04. Базовая статистика

- Количество активных студентов
- % преподавателей с контентом
- Количество отсутствий за период
- (простые графики)

## SA01. Суперадмин

- Список вузов
- Подключение нового вуза
- Управление коннекторами
- Общая аналитика по платформе
- Управление доступами / тарифами (на будущее)
