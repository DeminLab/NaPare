# Экраны студента — детальное (Figma-подобное) описание

Формат каждого экрана:
- **Цель**
- **Структура (сверху вниз)**
- **Состояния**
- **Действия**
- **Навигация**

---

## S01. Splash / Загрузка

**Цель:** показать бренд при старте.

- Центр: логотип НаПаре + короткий слоган
- Индикатор загрузки (если идёт проверка сессии)
- После проверки → Welcome или Мой день

---

## S02. Welcome (первый запуск)

**Структура:**
1. Верх: логотип
2. Заголовок: «Твой учебный день в одном месте»
3. Подзаголовок: «Расписание, задания, материалы и отсутствия — вокруг каждой пары»
4. Кнопка Primary: «Начать»
5. Текст-ссылка: «Уже есть аккаунт? Войти»
6. Внизу мелким: ссылки на Политику и Соглашение

---

## S03. Ввод телефона

**Структура:**
1. Заголовок: «Введите номер телефона»
2. Подзаголовок: «Мы отправим код подтверждения»
3. Поле телефона (маска +7)
4. Кнопка Primary: «Получить код» (disabled пока номер невалиден)
5. Ссылка «Войти по email» (для преподавателей)

**Ошибки:** «Неверный формат номера»

---

## S04. Ввод SMS-кода

**Структура:**
1. Заголовок: «Код из SMS»
2. Подзаголовок: «Отправили на +7 ••• ••• •• 21»
3. 4–6 отдельных ячеек для цифр (автофокус, автопереход)
4. Таймер: «Отправить снова через 0:47»
5. Ссылка «Изменить номер»

**Ошибки:** «Неверный код», «Код истёк»

---

## S05. Согласие на ПДн

**Структура:**
1. Заголовок: «Почти готово»
2. Чекбокс 1 (обязательный): «Я согласен на обработку персональных данных» + ссылка на Политику
3. Чекбокс 2 (обязательный при использовании статусов болезни): «Я согласен на обработку данных о состоянии здоровья в целях учёта отсутствий»
4. Кнопка Primary: «Продолжить» (disabled пока не отмечены обязательные)

---

## S06. Выбор вуза

**Структура:**
1. Заголовок: «Выберите учебное заведение»
2. Поиск
3. Список вузов (СИБИТ первым в пилоте)
4. Карточка вуза: название + город

**Пустое:** «Ничего не найдено» + «Сообщить о своём вузе»

---

## S07. Выбор факультета → курса → группы

Каскад из трёх экранов или один экран с тремя селектами.

**Финальный шаг:**
- Показывается выбранная группа
- Кнопка «Это моя группа»

---

## S08. Профиль (имя + аватар)

1. Заголовок: «Как вас зовут?»
2. Поле Имя
3. Поле Фамилия
4. Аватар (тап → выбор фото / генерация инициалов)
5. Кнопка «Готово»

---

## S09. Онбординг-тур (3–4 экрана)

Карусель:
1. «Это твой день» — объяснение Мой день
2. «Пространство пары» — контент вокруг занятия
3. «Статус отсутствия» — как отметить, что не придёшь
4. Кнопка «Начать пользоваться» → Мой день

---

## S10. Мой день (Главный)

**Шапка (фиксированная):**
- Слева: «Привет, Алекс» + дата
- Справа: колокольчик (бейдж) + аватар

**Контент (скролл):**
1. **Статус отсутствия** (если есть) — цветной чип + «Изменить»
2. **Сводка дня** — карточка с 4 метриками в ряд (пары / изменения / дедлайны / новое)
3. **Секция «Ближайшие пары»**
   - Заголовок секции
   - Список карточек пар:
     - Левая полоска цвета (по типу/статусу)
     - Время
     - Название предмета (H3)
     - Преподаватель • Аудитория
     - Бейдж «Изменено» если есть
4. **Секция «Горящие дедлайны»**
   - Карточки ДЗ с названием, предметом, дедлайном, статусом
5. **Секция «Новое»**
   - Превью объявлений и файлов

**Пустые состояния:** отдельные блоки «Сегодня пар нет», «Нет горящих дедлайнов».

**Действия:** pull-to-refresh, тап по любой карточке.

---

## S11. Расписание

**Переключатель:** День | Неделя

**Режим День:**
- Список пар по времени
- Карточка = время + предмет + преп + аудитория + бейдж изменений
- Тап → Пространство пары

**Режим Неделя:**
- Список дней или простая сетка
- Сегодня выделен
- Индикаторы изменений на дне

**Дополнительно:** фильтр «Только с изменениями», кнопка «История изменений» у пары.

---

## S12. Пространство пары

**Шапка:**
- Назад
- Название предмета
- Дата • время • аудитория
- Преподаватель

**Вкладки (горизонтальный скролл или fixed tabs):**
Объявления | Задания | Файлы | Обсуждение | Состав

**Объявления:**
- Список карточек (автор, время, текст)
- Пусто: «Преподаватель ещё ничего не написал»

**Задания:**
- Карточка: название, описание (expandable), дедлайн, статус
- Кнопка «Отметить как сданное» / «Сдано ✓»

**Файлы:**
- Список: иконка типа + название + размер + кнопка скачать

**Обсуждение:**
- Лента сообщений (свои справа / чужие слева)
- Поле ввода + кнопка отправить
- Поддержка простого ответа (цитата)

**Состав:**
- Список студентов группы (имя + аватар)

---

## S13. Мои задания

- Фильтры-чипы: Все | Не сдано | Сдано | Просрочено
- Список карточек ДЗ (предмет, название, дедлайн, статус)
- Тап → Пространство пары на вкладку Задания

---

## S14. Статус отсутствия

**Основной экран:**
- Большая карточка текущего статуса
- Период
- Количество затронутых пар
- Кнопка «Изменить статус»
- История прошлых статусов

**Экран / bottom sheet выбора:**
1. Список статусов с иконками и цветом
2. Выбор периода (Сегодня / Диапазон дат / Конкретные дни)
3. Если «Другая причина» — текстовое поле
4. Предупреждение: «Будет затронуто N пар. Куратор получит уведомление.»
5. Кнопка «Подтвердить»

---

## S15. Центр уведомлений

- Список, сгруппированный по дням
- Иконка типа + заголовок + время + превью
- Непрочитанные — жирным / точкой
- Тап → deep link
- Кнопка «Прочитать все»
- Свайп — отметить прочитанным (опционально)

---

## S16. Профиль и настройки

1. Аватар + ФИО + группа + вуз
2. Секция «Уведомления» — список переключателей по типам
3. Тема: Светлая / Тёмная / Системная
4. Язык: RU / EN
5. Ссылки: Политика, Соглашение, Поддержка
6. Кнопка «Выйти»
7. Опасная зона: «Удалить аккаунт»

---

## Общие состояния для всех экранов

- Loading (скелетоны предпочтительнее спиннеров)
- Error (текст + кнопка «Повторить»)
- Empty
- Offline (баннер «Нет сети. Показаны сохранённые данные»)
