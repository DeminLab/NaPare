# API contract reference

This file used to contain a manually maintained endpoint catalogue. It fell out of sync with the backend and must not be treated as a complete or generated contract.

The live contract is generated by NestJS Swagger from the backend code:

- Swagger UI: `/api/v1/docs`
- OpenAPI JSON: `/api/v1/docs-json`
- Local default origin: `http://localhost:3000`

For a static delivery snapshot, see the instructions in [API README](README.md) and [case OpenAPI export](../../scripts/export-case-openapi.sh). The export script requires a running HTTPS public endpoint (or local loopback) and writes into `deliverables/educational-solutions/openapi.json`.

Before changing a client/API contract, inspect the controller, DTOs, guards and service, then compare the generated OpenAPI. Do not copy request/response examples from the old hand-written catalogue.
