# Модель угроз

Базовый анализ угроз для MVP.

---

## Угрозы и митигация

| # | Угроза | Вероятность | Влияние | Митигация |
|---|--------|-------------|---------|-----------|
| 1 | Несанкционированный доступ к БД | Низкое | Критическое | RLS, шифрование, least privilege |
| 2 | Утечка паролей/токенов | Среднее | Критическое | Хеширование, HttpOnly cookies, HTTPS |
| 3 | XSS атака на web | Среднее | Высокое | CSP header, sanitize ввода |
| 4 | SQL инъекция | Низкое | Критическое | Parameterized queries (TypeORM) |
| 5 | XSS в MAX Mini-App | Среднее | Среднее | CSP, валидация initData |
| 6 | CSRF атака | Низкое | Среднее | CSRF tokens, SameSite cookies |
| 7 | DoS на API | Среднее | Высокое | Rate limiting, WAF (Cloudflare) |
| 8 | Утечка данных о здоровье | Низкое | Критическое | Шифрование причин, ограничение доступа |
| 9 | Social engineering (студент) | Среднее | Низкое | Обучение, 2FA (после MVP) |
| 10 | Компрометация refresh token | Низкое | Среднее | HttpOnly, Secure, IP-binding |

---

## Базовые контрмеры

| Категория | Меры |
|-----------|------|
| Сеть | HTTPS, HSTS, CSP, CORS |
| Аутентификация | JWT, rate limiting, lockout |
| Авторизация | Role-based access, university_id isolation |
| Данные | Шифрование at rest (AES-256), bcrypt для паролей |
| Логирование | AuditLog для критических действий |
| Инфраструктура | Docker, secrets management, регулярные обновления |

---

## Процедура реагирования на инцидент

1. **Обнаружение:** алерт из Sentry / мониторинга
2. **Оценка:** критичность (угроза данных → немедленно)
3. **Изоляция:** блокировка скомпрометированных аккаунтов
4. **Расследование:** анализ логов, определение объёма
5. **Устранение:** патч, ротация ключей
6. **Уведомление:** пользователи + Роскомнадзор (при необходимости)
7. **Документирование:** пост-мор tem
