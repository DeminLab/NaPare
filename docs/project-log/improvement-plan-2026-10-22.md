## Ключевая находка: изоляция вузов держится на одном guard

`apps/backend/src/common/guards/university.guard.ts` проверяет `universityId` только из `params.universityId` или `params.id`. Если маршрут не содержит этих параметров, guard пропускает запрос. Если `params.id` — это id не вуза (пара, пользователь, заявка), сравнение с `universityId` бессмысленно. Значит, изоляция данных зависит от того, что каждый сервис сам фильтрует по `university_id`. Это главный риск для мультивузовой платформы.

## P0-1. Изоляция данных между вузами

**Задача.** Гарантировать, что пользователь одного вуза не читает и не меняет данные другого, на уровне БД и на уровне API.

**Шаги.**
1. Перечислить все контроллеры и маршруты (`*.controller.ts`) и для каждого отметить, как определяется вуз: из JWT, из параметра, из связанной сущности.
2. Переписать `UniversityGuard`: для маршрутов с `:universityId` сравнивать именно с ним; для остальных маршрутов требовать, чтобы сервис получал `universityId` из пользователя, а не из запроса.
3. Ввести PostgreSQL Row Level Security на таблицах с `university_id` (миграция + `SET app.university_id` в транзакции на каждый запрос).
4. Добавить набор интеграционных тестов: два вуза, пользователь A пытается прочитать и изменить объекты вуза B по каждому маршруту. Тест падает, если доступ открыт.

**Промпт для ИИ:**
> Работай в репозитории NaPare, сначала прочитай AGENTS.md и docs/ai/change-safety.md. Задача: проверить изоляцию данных между университетами. Для каждого контроллера в apps/backend/src составь таблицу: маршрут, откуда берётся university_id, фильтр в сервисе. Найди маршруты, где university_id берётся из тела или параметров запроса без проверки. Исправь UniversityGuard так, чтобы он не пропускал запросы без явной проверки вуза. Напиши интеграционные тесты для двух вузов. Не меняй контракты API и Docker-конфигурацию без необходимости; если меняешь, опиши это отдельно. Запусти pnpm lint, typecheck и тесты backend.

**Критерий готовности:** таблица изоляции по всем маршрутам в `docs/security/tenant-isolation.md`; тесты на чужой вуз проходят; RLS включён на всех таблицах с `university_id`.
