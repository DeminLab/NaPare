Исторические материалы и проектные спецификации сохраняются со своими статусами; они не являются подтверждённой реализацией.

При проверке Markdown учитываются локальные ссылки вне блоков кода; внешние сайты и якоря заголовков отдельно не проверяются. Действительность canonical source paths проверяет `verify-ai-documentation.cjs`.

Удаление временных диагностических файлов `.playwright-cli/` и Python `__pycache__` отклонено автоматической проверкой безопасности среды. Файлы остаются локально; для них и `output/` добавлены исключения Git. Снимки прошлых браузерных прогонов сохранены локально; ссылки на них убраны из общедоступной документации. Зависимости, данные, ключи подписи, `.env`, исходники legacy-клиентов и история не удалялись.
