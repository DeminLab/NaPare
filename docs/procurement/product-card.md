# Карточка продукта НаПаре — проект

Дата: 22 октября 2026. Основание: кандидат `codex/improvement-integration`, не production. Назначение: первичный разговор с вузом и подготовка состава пилота.

| Поле | Сведения |
| --- | --- |
| Наименование | НаПаре |
| Назначение | Сопровождение учебного дня: расписание, контекст пары, подготовка, отсутствия и взаимодействие участников |
| Аудитория | Студенты, преподаватели/кураторы, сотрудники учебного офиса, администратор вуза; отдельно платформенные права и карьерные роли |
| Интерфейсы | Web/PWA студента, web сотрудников/администратора/платформы, публичный портал; Android WebView-клиент. Работа на реальных устройствах проверяется отдельно |
| Интеграции кандидата | CSV/JSON/ICS/XLSX, Moodle, СИБИТ; уведомления RuStore/WebPush/MAX/Telegram с выключенной по умолчанию внешней отправкой |
| Учебный офис | Заявления/этапы/решения и назначения в пределах своего вуза; технические роли не получают учебных прав автоматически |
| Оценки | Текущее состояние настроенных курсов Moodle, источник и страницы; нет подключённого официального реестра задолженностей |
| Offline | Явно сохранённое расписание с ограниченным сроком/объёмом, очищаемое при выходе; не весь портал офлайн |
| Оплата | Код Т-Кассы для услуг платформы; без выплат студентам. Договор/терминал/фискализация/live-платежи не подтверждены |
| Размещение | Варианты SaaS на согласованной площадке РФ или установка у заказчика; фактическая площадка и её соответствие не подтверждены |
| Права | В репозитории LICENSE Apache-2.0. Юридический правообладатель, цепочка исключительных прав и договорная модель требуют документов владельца |
| Цена, НДС, SLA | Не утверждены; состав и условия заполняются по запросу заказчика |
| Реестровая запись/сертификаты | Подтверждённый номер реестра российского ПО и сертификат ФСТЭК в рамках проверки не предоставлены; не заявляются как имеющиеся |
| Поставщик и контакты | [Юридическое лицо/ИП/иной допустимый заявитель, реквизиты и контакт — заполнить владельцу] |

Локально объединённый backend прошёл 422 unit и 4513 E2E тестов с одной пропущенной проверкой native host; внешние сервисы замещены тестовыми ответами. [Границы проверки и draft PR 1–12](../project-log/improvement-integration-2026-10-22.md). Эти результаты не являются SLA, аттестацией, подтверждением размещения данных или внедрением у заказчика.

До договора уточняются нагрузка/срок/модули, источник данных, роли оператора/обработчика, лицензии, резервное копирование, поддержка, приёмка и порядок завершения. Экспорт/обезличивание, полный WCAG-аудит, ИНН/модерация/XLSX и реальные внешние подключения остаются открытыми: [журнал плана](../project-log/improvement-progress-2026-10-22.md). Не использовать это описание как обещание уже работающих пилотов, измеренной экономии или официального статуса.
