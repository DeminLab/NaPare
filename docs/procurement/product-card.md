# Карточка продукта НаПаре — проект

Обновлено: 25 октября 2026. Основание: кандидат `codex/improvement-integration`, не production. Назначение: первичный разговор с вузом и подготовка состава пилота. Реквизиты, тарифы и налоговый режим пользователь предоставит позже; они не утверждены.

| Поле | Сведения |
| --- | --- |
| Наименование | НаПаре |
| Назначение | Сопровождение учебного дня: расписание, контекст пары, подготовка, отсутствия и взаимодействие участников |
| Аудитория | Студенты, преподаватели/кураторы, сотрудники учебного офиса, администратор вуза; отдельно платформенные права и карьерные роли |
| Интерфейсы | Web/PWA студента, web сотрудников/администратора/платформы, публичный портал; Android WebView-клиент. Работа на реальных устройствах проверяется отдельно |
| Интеграции кандидата | CSV/JSON/ICS/XLSX, Moodle, СИБИТ; уведомления RuStore/WebPush/MAX/Telegram с выключенной по умолчанию внешней отправкой |
| Учебный офис | Заявления/этапы/решения и назначения своего вуза; отчёты текущих аккаунтов и подтверждённые полные снимки долгов групп с историей/пагинацией/CSV. Подлинность реального вузовского источника не подтверждена |
| Оценки | Текущее состояние настроенных курсов Moodle, источник и страницы; нет подключённого официального реестра задолженностей |
| Offline | Явно сохранённое расписание с ограниченным сроком/объёмом, очищаемое при выходе; не весь портал офлайн |
| WebPush | Экран портала, явное разрешение, отдельный service worker, отзыв при logout и очистка после удаления. Browser permission/PushManager и provider в проверках подменены; реальное устройство не проверено |
| Карьерный центр | JSON/XLSX-отчёт задач/откликов/принятых работ, ИНН-адаптер и ручная модерация/жалобы. Отчёт не подтверждает трудоустройство или зачёт практики; live-проверка конкретной компании отдельно |
| Данные аккаунта | Self JSON export и удаление профиля/приватных наборов с сохранением учебного архива под кодом. Это псевдонимизация; внешние файлы/источники/логи/backup требуют операторской процедуры |
| Аналитика | Десять определённых метрик своего вуза и наблюдаемая готовность подключения. Сбор активности выключен по умолчанию; политика, периоды и реальная настройка вузом требуют согласования |
| Оплата | Код Т-Кассы для услуг платформы; без выплат студентам. Договор/терминал/фискализация/live-платежи не подтверждены |
| Размещение | Варианты SaaS на согласованной площадке РФ или установка у заказчика; фактическая площадка и её соответствие не подтверждены |
| Права | В репозитории LICENSE Apache-2.0. Юридический правообладатель, цепочка исключительных прав и договорная модель требуют документов владельца |
| Цена, НДС, SLA | Не утверждены; состав и условия заполняются по запросу заказчика |
| Реестровая запись/сертификаты | Подтверждённый номер реестра российского ПО и сертификат ФСТЭК в рамках проверки не предоставлены; не заявляются как имеющиеся |
| Поставщик и контакты | [Юридическое лицо/ИП/иной допустимый заявитель, реквизиты и контакт — заполнить владельцу] |

Кандидат включает PR 1–12 и 14–28. [CI PR 28](https://github.com/DeminLab/NaPare/actions/runs/40119582581) подтвердил все шесть jobs, в том числе Linux build и 4869 E2E-тестов с одной пропущенной проверкой host agent. Внешние провайдеры в предметных тестах подменены. [Границы проверки интеграции](../project-log/improvement-integration-2026-10-22.md). Эти результаты не являются SLA, аттестацией, подтверждением размещения данных или внедрением у заказчика.

До договора уточняются нагрузка/срок/модули, источник данных, роли оператора/обработчика, лицензии, backup, поддержка, приёмка и порядок завершения. Реальные источники и устройства, полная ручная доступность, внешние копии после удаления, фактическое размещение и юридические документы остаются открытыми: [журнал плана](../project-log/improvement-progress-2026-10-22.md). Не использовать эту карточку как обещание уже работающих пилотов, измеренной экономии или официального статуса.
