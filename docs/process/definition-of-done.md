# Definition of Done (DoD)

Задача считается выполненной, когда **все** пункты ниже отмечены.

---

## Код

- [ ] Код написан и проходит linting
- [ ] Код покрыт unit-тестами (min. покрытие см. [ops/testing.md](../ops/testing.md))
- [ ] Integration/E2E тесты написаны (если применимо)
- [ ] Нет секретов в коде (ключи, пароли, токены)

---

## Документация

- [ ] Модуль `modules/*.md` обновлён (если изменилась логика модуля)
- [ ] OpenAPI обновлён (если изменился API)
- [ ] README обновлён (если изменился setup / структура)

---

## Критерии приёмки

- [ ] Все критерии приёмки из `modules/*.md` раздела 9 выполнены
- [ ] Работает на всех клиентах (mobile, web, max) если применимо
- [ ] Тёмная тема работает
- [ ] Accessibility не ухудшена

---

## Безопасность

- [ ] Нет SQL-инъекций (parameterized queries)
- [ ] XSS защита (sanitize ввода)
- [ ] Роли и права работают корректно
- [ ] Rate limiting работает (если применимо)
- [ ] Аудит логируется (если применимо)

---

## Deploy

- [ ] Проходит CI (lint + test + build)
- [ ] Работает на staging
- [ ] Работает на production (после деплоя)

---

## Как использовать

При code review — проверять каждый пункт. Если что-то не выполнено — PR не мержить.

При работе AI-агента — проверять по этому чеклисту перед отправкой кода.
