# Видение

## Проблема

Учебный процесс студента разбросан по десяткам мест: расписание на сайте вуза, изменения в Telegram, домашка в чатах, файлы в облаках, отсутствия — устно куратору.

**Итог:** студент тратит время на поиск информации об учёбе, а не на учёбу.

## Решение

**НаПаре** — операционная система учебного дня студента.

```
Расписание → Конкретная пара → Контекст пары
                              (преподаватель, группа, файлы,
                               задания, объявления, обсуждение,
                               история изменений, посещаемость)
```

## Ключевые механики

1. **Пространство пары** — у каждого занятия своя страница
2. **Мой день** — персональная сводка без AI
3. **Центр статуса студента** — статусы с расчётом пар и подтверждением куратора
4. **Мультивузовость с рождения** — архитектура для любого вуза

## Целевая аудитория

- **Основные:** студенты вузов и колледжей (16–25 лет)
- **Вторичные:** преподаватели, кураторы, администрация

## Стратегия входа

1. MVP + пилот на СИБИТ (Омск)
2. Расширение внутри вуза и региона
3. Национальный и глобальный рост

## Долгосрочное видение

Стать инфраструктурным слоем учебного процесса — тем, чем Slack/Notion стали для команд, но для студентов и вузов.
