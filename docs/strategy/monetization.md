# Монетизация

## Модель

**B2B2C SaaS:** основной плательщик — учебное заведение. Студент пользуется бесплатно.

---

## Источники дохода

| # | Источник | Приоритет | Описание |
|---|----------|-----------|----------|
| 1 | SaaS-подписка для вузов | Основной | Pilot → Basic → Pro → Enterprise |
| 2 | Student+ | Позже | AI-ассистент, расширенная история |
| 3 | Аналитика для администрации | Позже | Глубокая аналитика посещаемости |
| 4 | Партнёрские интеграции | Позже | Работа, стажировки, курсы |
| 5 | White-label | Позже | Крупные сети, министерства |

---

## Тарифы

| Тариф | Кому | Ориентир |
|-------|------|----------|
| Pilot | Пилотный вуз | Бесплатно (0–3 мес) |
| Basic | Небольшой вуз | 50–100 тыс. руб./год |
| Pro | Средний/крупный | Цена за студента в год |
| Enterprise | Крупный вуз, сеть | Индивидуальный контракт |

---

## Цикл продаж

1. **Пилот бесплатно** (0–3 мес) → метрики, NPS, кейсы
2. **Платный переход** (3–6 мес) → годовой контракт
3. **Региональный рост** (6–14 мес) → рекомендации, соседние вузы
4. **B2B-масштабирование** (14+ мес) → выставки, конференции

---

## Юнит-экономика

- CAC на один вуз
- Время до первого платежа
- LTV вуза (удержание 2–3+ года)
- % студентов → ежедневные пользователи
