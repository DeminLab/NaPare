## 1. Общие положения

1.1. Настоящая Политика обработки персональных данных (далее — Политика) действует в отношении всех персональных данных, которые пользователь может предоставить о себе при регистрации и использовании сервиса НаПаре (далее — Сервис).

1.2. Оператор ставит своей важнейшей целью и условием осуществления своей деятельности соблюдение прав и свобод человека и гражданина при обработке его персональных данных, в том числе защиту прав на неприкосновенность частной жизни, личную и семейную тайну.

1.3. Настоящая Политика применяется ко всем данным, которые Оператор может получить о пользователях Сервиса.

1.4. Пользователь гарантирует, что все предоставляемые ему данные являются достоверными и актуальными.

## 2. Какие персональные данные мы собираем

### 2.1. Данные, предоставляемые пользователем

| Данные | Обязательность | Цель сбора |
|--------|----------------|------------|
| Номер телефона | Обязательно | Регистрация, вход, верификация |
| Имя и фамилия | Обязательно | Идентификация в системе |
| Аватар | Опционально | Персонализация |
| Email | Опционально | Восстановление доступа, уведомления |
| Учебное заведение, группа | Обязательно | Формирование расписания и доступа |
| Причина отсутствия | Опционально | Учёт отсутствий (особая категория) |

### 2.2. Технические данные (автоматический сбор)

| Данные | Цель |
|--------|------|
| Device token | Push-уведомления |
| IP-адрес | Безопасность, аудит |
| Версия приложения | Аналитика, поддержка |
| История входов | Безопасность (AuditLog) |

### 2.3. Особо защищаемые персональные данные

- **Причины отсутствий, связанные со здоровьем** — обрабатываются только с отдельного согласия пользователя. Преподаватель видит факт отсутствия, но не видит причину. Куратор видит причину, но только для своей группы.

3.1. Предоставление доступа к Сервису.

3.6. Обеспечение безопасности (аутентификация, аудит).  
3.7. Аналитика и улучшение Сервиса.  
3.8. Исполнение требований законодательства РФ.

## 4. Правовые основания обработки

4.1. Федеральный закон от 27.07.2006 № 152-ФЗ «О персональных данных».  
4.2. Согласие субъекта персональных данных, выраженное при регистрации.  
4.3. Договор между пользователем и Оператором (Пользовательское соглашение).  
4.4. Законные интересы Оператора (улучшение Сервиса, безопасность).

## 5. Порядок сбора, хранения и защиты данных

5.1. Оператор принимает необходимые организационные и технические меры для защиты персональных данных от неправомерного доступа, уничтожения, изменения, блокирования, копирования и распространения.

5.2. Персональные данные хранятся на серверах, расположенных на территории Российской Федерации, в соответствии с требованиями ст. 18 152-ФЗ.

5.3. Срок хранения персональных данных:
- Активные данные — срок действия аккаунта пользователя
- Данные после удаления аккаунта — 30 дней (техническое резервное копирование)
- AuditLog — 1 год
- Данные о здоровье (причины отсутствий) — не хранятся дольше необходимого для обработки статуса

5.4. Доступ к персональным данным имеют только уполномоченные сотрудники Оператора, ознакомленные с настоящей Политикой.

## 6. Передача данных третьим лицам

6.1. Оператор не продаёт и не передаёт персональные данные третьим лицам без согласия пользователя, за исключением следующих случаев:

| Случай | Третья сторона | Основание |
|--------|----------------|-----------|
| SMS-уведомления | Провайдер SMS-рассылок | Исполнение регистрации |
| Push-уведомления | Firebase (Google) / Apple (APNs) | Предоставление Сервиса |
| Хранение файлов | Yandex Object Storage / MinIO | Предоставление Сервиса |
| Аналитика | PostHog / Amplitude | Улучшение Сервиса |
| Мониторинг ошибок | Sentry | Обеспечение стабильности |
| По требованию закона | Государственные органы | Исполнение законодательства |

6.2. При передаче данных Оператор обеспечивает их защиту с помощью договоров и технических мер.
