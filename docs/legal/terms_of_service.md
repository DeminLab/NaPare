## 1. Определения

1.1. **Сервис** — операционная система учебного дня студента «НаПаре», включающая мобильное приложение, веб-приложение и мини-приложение мессенджера MAX.

1.3. **Контент** — любые материалы, размещённые Пользователем в Сервисе (объявления, задания, файлы, сообщения).

1.4. **Оператор** — [наименование организации / ИП], владеющий Сервисом.

## 2. Предмет соглашения

2.1. Настоящее Соглашение определяет условия использования Сервиса Пользователем.

2.2. Использование Сервиса означает принятие условий настоящего Соглашения.

2.3. Оператор предоставляет Пользователю право использования Сервиса на условиях, изложенных в Соглашении.

## 3. Регистрация и аккаунт

3.1. Для доступа к Сервису Пользователь обязан пройти регистрацию, предоставив достоверные данные.

3.2. Пользователь несёт ответственность за сохранность данных своего аккаунта.

3.3. Пользователь обязуется не передавать данные аккаунта третьим лицам.

3.4. При обнаружении несанкционированного доступа Пользователь обязан немедленно уведомить Оператора.

3.5. Оператор вправе заблокировать аккаунт при обнаружении нарушений настоящего Соглашения.

## 4. Права и обязанности сторон

### 4.1. Оператор вправе:
- Изменять условия Соглашения с уведомлением Пользователя
- Ограничивать доступ к Сервису при нарушении условий
- Собиравать и обрабатывать технические данные для работы Сервиса
- Удалять контент, нарушающий условия Соглашения

### 4.2. Оператор обязуется:
- Обеспечивать стабильную работу Сервиса
- Защищать персональные данные Пользователя
- Не раскрывать данные третьим лицам без согласия (за исключением случаев п. 6 Политики конфиденциальности)
- Рассматривать обращения Пользователей в течение 30 дней

### 4.3. Пользователь вправе:
- Использовать Сервис в соответствии с его назначением
- Удалять свой аккаунт в любой момент
- Запрашивать информацию о своих данных

### 4.4. Пользователь обязуется:
- Предоставлять достоверные данные при регистрации
- Не нарушать работу Сервиса
- Не размещать контент, нарушающий законодательство РФ
- Не использовать Сервис для мошеннических действий

5.1. Пользователь сохраняет права на размещаемый Контент.

5.2. Пользователь предоставляет Оператору бессрочную лицензию на использование Контента в рамках работы Сервиса.

5.3. Пользователь обязуется не размещать:
- Материалы, нарушающие авторские права
- Неприемлемый или вредоносный контент
- Персональные данные других лиц без их согласия
- Спам и рекламные сообщения

5.4. Оператор вправе удалить Контент, нарушающий п. 5.3, без предупреждения.

6.2. Пользователь несёт ответственность за содержание размещаемого Контента.

6.3. Ограничение ответственности Оператора не распространяется на случаи, предусмотренные законодательством РФ.
