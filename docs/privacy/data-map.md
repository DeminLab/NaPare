## Что означает удаление сейчас

В [UsersController](../../apps/backend/src/users/users.controller.ts) `DELETE /users/me` вызывает `deactivate()`. Это блокировка аккаунта, **не уничтожение и не обезличивание**. Обещание удаления всех данных из профиля пока недопустимо. 23 октября в рабочей ветке добавлен [self JSON export](personal-data-export.md): единый снимок активной БД, все страницы явных проекций, без секретов и полных произвольных журнальных JSON. Внешние архивы/байты файлов и общий пользовательский экран этим API не реализованы. Удаление остаётся открытым пунктом P2-1; пользователь выбрал [индивидуальный архив без имени и контактов](account-rights-model.md), то есть псевдонимизацию с перечислением исключений.

План обработки запроса: проверить личность → определить перечень данных и основания сохранения → прекратить лишние внешние потоки → удалить личные заметки/токены/привязки и доступные к удалению материалы → обезличить допустимые учебные записи с проверкой повторной идентификации → отдельно обработать файлы, audit и копии → выдать акт с исключениями и сроками. Это **спецификация процедуры**, она здесь не реализуется и над реальными данными не запускалась.

Не считать замену ФИО на «Удалён» достаточным обезличиванием: стабильные UUID, группа, даты, текст и внешние ID могут связать записи обратно. Решение об уничтожении учебного архива и обязательных финансовых записей нельзя принимать автоматически без матрицы оснований.

См. [оценку ПД](../legal/personal-data-assessment.md), [размещение](../legal/rf-deployment-assessment.md), [проект поручения](../legal/data-processing-agreement-draft.md).
