# Клиент: Web App (Next.js)

## Обзор

| Параметр | Значение |
|----------|----------|
| **Платформа** | Браузер (адаптивный) |
| **Стек** | Next.js 14+ (App Router), TypeScript, Tailwind, TanStack Query |
| **Аудитория** | Кураторы, админы, преподаватели, студенты на ПК |
| **Приоритет** | Критический |

---

## Роли и разделы

### Студент (веб-версия)

| Раздел | Описание |
|--------|----------|
| Мой день | Агрегированная сводка |
| Расписание | Неделя / день / месяц |
| Пространство пары | Объявления, ДЗ, файлы, обсуждение |
| Задания | Список ДЗ с фильтрами |
| Статус отсутствия | Установка / изменение статуса |
| Профиль | Настройки |

### Преподаватель

| Раздел | Описание |
|--------|----------|
| Мои пары | Список пар |
| Быстрая публикация | Контент в пространство пары |
| Список отсутствующих | На конкретной паре |

### Куратор

| Раздел | Описание |
|--------|----------|
| Дашборд отсутствий | Таблица с фильтрами |
| Подтверждение / отклонение | Быстрые действия |
| Объявления группе | Массовая рассылка |
| Расписание группы | Просмотр |

### Админ вуза

| Раздел | Описание |
|--------|----------|
| Структура | Факультеты, группы |
| Загрузка расписания | Файл + маппинг |
| Назначение ролей | Управление пользователями |
| Статус синхронизации | Коннекторы |
| Базовая статистика | Графики |

### Суперадмин

| Раздел | Описание |
|--------|----------|
| Подключение вузов | CRUD университетов |
| Управление коннекторами | Настройка |
| Общая аналитика | По платформе |

---

## Адаптивность

| Breakpoint | Ширина | Поведение |
|------------|--------|-----------|
| Mobile | < 768 | Мобильная версия |
| Tablet | 768–1023 | Промежуточная |
| Desktop | ≥ 1024 | Полноценные таблицы, сайдбар |

---

## Технические требования

- App Router
- Server Components где возможно
- TanStack Query для кэширования
- Role-based routing и layout
- Тёмная тема (next-themes)

---

## Критерии приёмки

- [ ] Куратор видит и обрабатывает отсутствия
- [ ] Админ загружает расписание
- [ ] Роли работают корректно
- [ ] Адаптивен на телефоне и десктопе
- [ ] Тесты ≥ 75% покрытия
- [ ] First Contentful Paint ≤ 1.5 сек
