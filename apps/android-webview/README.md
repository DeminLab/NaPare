# НаПаре для Android

Android-клиент действующего сайта `https://napare.sano.ru` с нативным локальным планом. Android 8.0+ (API 26), compile/target SDK 35, Java 17, Gradle 8.11.1, AGP 8.9.2. Релиз-кандидат 1.1.0 (versionCode 2); публикация в RuStore не выполнялась.

## План офлайн

Кнопка «План офлайн» доступна в нативной нижней панели даже при недоступном сайте. Можно добавить записи на день, указать время, заметку, отметить выполнение, изменить/удалить запись и отправить план через Android Sharesheet. Записи хранятся только в приватном каталоге приложения; автоматически на сервер не передаются. Это ручной органайзер, не кеш университетского расписания. Лимит — 200 записей, название до 160 символов, заметка до 1000. Запись файла атомарна; повреждённый файл не заменяется при чтении.

План не привязан к аккаунту. При смене пользователя записи остаются на устройстве. «Ещё → Удалить весь локальный план» удаляет записи после подтверждения, не меняя аккаунт и сайт. Удаление приложения также удаляет его приватные данные. Облачный backup и device transfer исключены настройками приложения. «О приложении» содержит информацию о локальных данных и путь к `/privacy`; публичная политика требует отдельной публикации на сайте.

При новом запуске Activity открывается `/login`; перед показом формы удаляются только `accessToken` и `refreshToken` этого сайта. Нужно снова войти по email и паролю. Переход к кабинету определяется существующим серверным входом сайта. Возвращение из браузера, выбора файла и обычное сворачивание не сбрасывают текущую сессию. Поворот экрана сохраняет текущую страницу.

Сайт отображается без адресной строки. Доступны история кнопки «Назад», индикатор загрузки, сетевой экран с повтором, подтверждения JavaScript, системный выбор файлов и сохранение календаря `.ics`. Для календаря используется origin-scoped WebMessageListener AndroidX; старый WebView без этой возможности показывает просьбу обновить Android System WebView. Другие HTTPS-загрузки и внешние ссылки открываются в браузере. Доставка сообщений MAX и browser/OS sharing зависят от установленных приложений и не гарантируются оболочкой.

HTTP и mixed content запрещены; ошибки сертификатов не обходятся. WebView открывает только точный HTTPS-хост `napare.sano.ru`, сторонние ссылки уходят наружу. Нет JavaScriptInterface, доступа к произвольным файлам, разрешений камеры/микрофона, нативного push или нового backend. Приложение требует интернет; это не полноценная офлайн-копия сайта. Изменения сайта не требуют обновления APK.

## Сборка

Нужны Java 17, Android SDK platform 35 и build-tools 35.0.0. Wrapper получает Gradle из официального distribution. Подпись хранится вне репозитория; приватный JSON имеет поля `store` (абсолютный путь keystore), `password`, `alias`. Никогда не коммитить этот JSON или keystore.

```powershell
./scripts/build-android.ps1 -AndroidSdk 'C:/Android/Sdk' -JavaHome 'C:/Program Files/Java/jdk-17' -SigningConfigPath 'C:/private/napare-release.private.json'
```

Команда запускает `assembleRelease`, `lintRelease`, `testReleaseUnitTest`, проверяет подпись и копирует APK в игнорируемый `outputs/android`. Имя артефакта берётся из versionName APK, рядом сохраняется build-result.json без секретов. Опциональный `-PreviousApkPath` проверяет совпадение сертификата с предыдущей сборкой. Сохраните приватный keystore и его пароль: последующие версии с этим applicationId нужно подписывать тем же ключом. Для новой версии увеличьте versionCode и versionName.

## Проверки перед распространением

Сборка, Android lint и JVM-тесты хранилища не доказывают работу на телефоне. На устройстве проверить новый запуск → email/пароль → кабинет своей роли, клавиатуру, поворот, «Назад», выход и повторный вход, потерю сети/повтор, файлы и сохранение `.ics`. Отдельно проверить внешние ссылки. Для плана проверить создание/изменение/удаление/выполнение, смену даты, отправку и сохранение после полного закрытия приложения без сети. Установка в Google Play и push не входят в эту поставку.

Пошаговая инструкция и оставшиеся препятствия модерации: [RuStore](../../docs/deployment/rustore-publication.md). Метаданные в `rustore/` — черновик карточки; пароли модераторских аккаунтов туда не сохранять.

Документация платформы: [WebView](https://developer.android.com/develop/ui/views/layout/webapps/webview), [WebViewCompat](https://developer.android.com/reference/androidx/webkit/WebViewCompat).
