# Anthropic Frontend Design: дополнительный источник

Существующий frontend-design сохранён. Этот навык имеет отдельное имя для исключения подмены. Источник: upstream/SKILL.original.md; LICENSE.txt содержит Apache-2.0.

1. Прочитать AI_CONTEXT.md и задачу; определить целевой маршрут, пользователя и критерий результата.
2. Прочитать upstream/SKILL.original.md как рекомендации по композиции и типографике. При конфликте следовать AGENTS.md, packages/design-tokens и текущему бренду НаПаре.
3. Сохранить реальные API, права, контент и состояния. Не добавлять доминирующие анимации/новые шрифты/придуманные данные ради эстетики.
4. Использовать существующие компоненты packages/ui. Проверять Figma через доступный MCP лишь для указанного файла.
5. Подтвердить результат в Playwright на целевых маршрутах и размерах; DevTools — ошибки сети, console и производительность по задаче.
6. Передать результат с конкретными проверками и оставшимися пробелами. В этом задании DevKit интерфейсы не переделывать.
