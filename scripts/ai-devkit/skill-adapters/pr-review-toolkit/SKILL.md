# PR Review Toolkit для Codex

Текстовые профили шести upstream reviewers в agents/ — справочные материалы, не регистрация Claude subagents. Slash command в commands/review-pr.md описывает upstream и не выполняется как команда Codex.

1. Прочитать AI_CONTEXT.md, AGENTS.md и требования задачи. Зафиксировать base/head, получить git diff и список файлов; выбрать только затронутые профили.
2. Прочитать agents/code-reviewer.md для общего ревью, silent-failure-hunter.md для ошибок, type-design-analyzer.md для инвариантов, pr-test-analyzer.md для тестов, comment-analyzer.md для документации. code-simplifier.md применять как рекомендации, не автоматический рефакторинг.
3. Читать актуальные определения и вызовы; доказывать конкретный триггер и последствия. Для НаПаре отдельно проверить tenant/university/group scope, refresh auth, RLS, DTO/API и миграции.
4. Если пользователь разрешил параллельную работу, использовать доступных Codex subagents с непересекающейся задачей и одним итоговым review. Иначе выполнить профили последовательно. Имена моделей/tools из Claude metadata не задают права Codex.
5. Проверки выполнять локально на синтетических данных. GitHub MCP использовать для чтения PR/CI; не публиковать комментарии и не менять PR без явного задания.
6. Отчет: приоритет, абсолютный путь/строка, воспроизводимый сценарий, последствие, рекомендация. Отделить доказанный дефект от гипотезы; отсутствие находок не доказывает отсутствие ошибок.

Готово, когда каждая находка подтверждена кодом или тестом, проверены границы задачи, а непроверенные browser/runtime/security сценарии перечислены явно. Не требовать новых бессмысленных тестов для текстовых изменений.
