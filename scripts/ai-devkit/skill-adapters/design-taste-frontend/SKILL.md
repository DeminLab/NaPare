# Taste Skill для NaPare

Текстовая адаптация. Upstream hooks, gate, shell scripts, assets и генераторы не установлены и не запускаются. Исходный SKILL в upstream/SKILL.original.md служит атрибуцией; его правила не заменяют следующие ограничения.

1. Изучить AI_CONTEXT.md, packages/design-tokens, packages/ui и код целевого приложения. Определить аудиторию, задачу страницы и имеющиеся реальные материалы.
2. Прочитать только нужный reference из references/: copy-voice.md для текста, system.md для цельности, perf.md для производительности. Правила бренда и фактические данные НаПаре главнее.
3. Сформировать одну обоснованную композицию: иерархия, типографика, ритм, реальные UI-состояния; обсуждать крупную смену направления в рамках задания.
4. Не переносить upstream предписания о контактах .example, обязательных фото, высоте секции в экран, декоративных сценах или принудительных анимациях в продукт. Не подменять юридические/контактные данные; не использовать фотозаглушки как факты.
5. Использовать Figma MCP только для предоставленного файла и доступных прав. Внедрять через существующие компоненты и tokens; учитывать prefers-reduced-motion.
6. Проверить Playwright на desktop/mobile, keyboard и состояния; в DevTools проверить layout shift и network. Без реального браузера не утверждать визуальную готовность.

Готово, когда дизайн решает задачу страницы, согласован с НаПаре, реальный контент читаем, действия работают и проверка документирована. Опциональные upstream references с командами читать как концептуальные материалы; их автоматические процедуры не включать.
